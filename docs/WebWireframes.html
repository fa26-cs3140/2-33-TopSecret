Wireframe 4: Access and request errors

Top Secret web view

Request outcomes

  • Missing, forged or expired server session: 303 /
  • Invalid form, duplicate parameter or nonpositive ID: 400
  • Standard user requesting audit: 403
  • Unknown authenticated page or missing record: 404
  • Attempt to create/edit over HTTP: 405 + Allow
  • Oversized login form: 413
  • Storage failure: generic 500; server continues serving

No passwords, tokens or backend details appear in error pages.

Application HTML uses forms, lists, links and tables. No CSS, JavaScript or web frameworks.
