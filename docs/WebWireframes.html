Compose a message

Top Secret | briefs | agents | facilities | missions | countries | Search | Messaging | Audit (admin) | [Log out]

GET /messages/new - New message

To: [Select an agent v]

Message: [multiline text area]

[Send message]   [Cancel]

The dropdown lists the current agents. Sending is available to standard users and administrators.

POST /messages/send checks a valid recipient, nonblank text (at most 4096 characters), exact form fields and the session CSRF token. Sender identity comes from the signed-in account.

Success redirects to the sender's inbox. Recipients see the new message as Unread; the sender has no special access to the recipient's inbox.

Expired/revoked sessions return to login without sending or marking a message. After signing in again, reload the form to obtain the new session's CSRF token.

All message text and names are escaped. Messaging creates no audit entries.

GET /audit - administrators only

Rows: timestamp | username | event | content type | ID. Newest first. Includes content access/changes and terminal session revocations.

Request outcomes

  • Missing, expired or revoked session: 303 to login.
  • Invalid forms or CSRF: 400; admin-only requests by standard users: 403.
  • Missing/foreign message or unknown record: 404.
  • Wrong method: 405; oversized form: 413; storage failure: generic 500.

Terminal session administration

Admin menu option 14 lists username, full issued token, creation time and last activity. Enter the full token to revoke it. The next browser request must log in again.

POST /create includes mission_id and the session CSRF token. Saving atomically creates the linked brief and redirects to its selected mission. Validation errors retain input and mission selection. Blank mission permits an unlinked brief.

Download briefs

GET /mission-briefs?mission_id=1 returns mission-1-briefs.json as an application/json UTF-8 attachment. Each record contains id, mission_id, title, date and text. Only briefs attached to this mission appear, in ID order. No briefs produces an empty array.

Missing mission: 404. Invalid ID/extra parameters: 400. Expired or missing session: redirect to login. Standard users may download but may not create briefs.
