Substitution Cipher

SubstitutionCipher implements Cipher. It deciphers text through a two-line key
supplied by FileHandler and performs no direct file access.


KEY FORMAT

Line 1 contains plain characters. Line 2 contains cipher characters in matching
positions. A character at position n on line 2 maps to position n on line 1.
Characters absent from the key pass through unchanged. Spaces are significant;
carriage returns and one trailing newline are normalized.


INTERFACE

  String decipher(String text, String keyFileName)

A null key filename selects ciphers/key.txt through FileHandler.


VALIDATION AND ERRORS

The key must exist, contain exactly two nonempty lines of equal length, and contain
no duplicate character on either line. Invalid keys raise InvalidCipherException.
Null input text or a null FileHandler raises IllegalArgumentException.

Tests cover mapping, pass-through characters, whitespace, line endings, malformed
keys, missing files, null values, alternate key routing and the supplied key.
