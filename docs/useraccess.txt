useraccess.txt - Member A

Access levels. Who a user is decides what the menu offers them and what the
program will actually do if they ask for it anyway.


THE TWO ROLES

  STANDARD   read content
  ADMIN      read content, add entries, create users, view the audit log,
             promote and demote other users

The first account created is always an ADMIN. Every account made after that
starts STANDARD. Role is set at creation and only an admin changes it later.


PROMOTING AND DEMOTING

  auth.promote(actingUsername, targetUsername)
  auth.demote(actingUsername, targetUsername)

The acting user must be an admin and cannot be the target. That one rule means
there is always at least one admin left, so nobody can lock the system. It is
also an error to promote someone who is already an admin, or demote someone who
is already standard.


HOW THE ROLE TRAVELS

  Session   username plus role, built once at login by auth.sessionFor(username)

TopSecret.main builds it after a successful login and hands it to
ui.runMenu(in, out, session). The audit log takes the username off it, and the
menu asks AccessControl what to draw.


CHECKING ACCESS

  access.canReadContent(session)
  access.canCreateContent(session)
  access.canCreateUsers(session)
  access.canViewAuditLog(session)
  access.canManageRoles(session)

Ask twice, not once. The menu asks to decide which options to print, and the
code doing the work asks again before it acts. Hiding a menu line is not
security on its own; someone can still type the number of an option they cannot
see. A null session answers false to everything, so an unexpected gap fails
closed rather than open.


WHERE THE ROLE IS STORED

Third tab-separated field in the ciphered credential file, next to the username
and password. Never in the database, same as passwords.

A line with only two fields is a file written before roles existed, and reads
as STANDARD. That means nobody has to delete their credential file again. A
line with an unknown role name, or more than three fields, is rejected as an
invalid file.
