Program Control

ProgramControl isolates user interaction from the numbered encrypted-file and
mission-search APIs. ProgramControlImpl delegates file access to FileHandler,
deciphering to Cipher and mission operations to MissionRepository/MissionSearch.


INTERFACE CONTRACT

  listFiles()
    Returns filenames in display order, or an empty list when none are available.

  getFileContents(number)
    Returns deciphered content using the default key.

  getFileContents(number, keyName)
    Returns deciphered content using the named key.

  listMissions()
    Returns persisted mission records.

  searchMissions(query)
    Returns case-insensitive matches from mission briefs.

Invalid selection, file, cipher and persistence failures are exposed as
ProgramControlException. The implementation does not print, exit or access files
directly.


DEPENDENCY FLOW

  TopSecret -> UserInterface -> ProgramControlImpl -> FileHandlerImpl
                                            -> SubstitutionCipher -> FileHandlerImpl
                                            -> MissionRepository / MissionSearch

Unit tests use small boundary stubs. Integration tests exercise the SQLite-backed
mission path. Run all checks with `./gradlew test` on macOS/Linux or
`.\gradlew.bat test` on Windows.
